PLAN D'IMPLÉMENTATION : SYSTÈME DE RÉCOMPENSES ET PROGRESSION

1. LE GESTIONNAIRE DE PROGRESSION (BACKEND)
   Objectif : Centraliser la sauvegarde et le chargement des éléments débloqués.
   Fichier cible : scripts/sProgressionManager.gml (à créer ou étendre sStoryProgress)

   Structure des données (Sauvegarde) :
   - unlocked_cards : Liste des IDs de cartes que le joueur possède.
   - unlocked_bots : Liste des IDs de bots que le joueur a vaincus et peut affronter à nouveau.
   - story_progress : État d'avancement (Chapitres/Actes complétés).

   Fonctions clés à implémenter :
   - unlock_card(card_id) : Ajoute l'ID à la liste si non présent.
   - unlock_bot(bot_id) : Ajoute le bot à la liste des adversaires disponibles.
   - unlock_chapter(chap_id) / unlock_act(act_id) : Valide la progression.
   - is_card_unlocked(card_id) : Retourne true/false.
   - is_bot_unlocked(bot_id) : Retourne true/false.

2. DÉCLENCHEURS DE RÉCOMPENSES (LOGIQUE JEU)

   A. Victoire en Duel (oGameOverScreen / oGame)
      Condition : Le joueur gagne le duel (LP Ennemi <= 0).
      Actions :
      - Bot : Appeler unlock_bot(bot_adversaire_id).
      - Cartes : Récupérer la liste des cartes du deck actuel du joueur.
                 Pour chaque carte, appeler unlock_card(carte_id).

   B. Fin d'Acte (oScenarioRunner)
      Condition : La dernière scène de l'acte est terminée.
      Actions :
      - Progression : Marquer l'acte comme complété (permet d'afficher les titres dans le menu).
      - Navigation : Débloquer l'accès au bouton de l'acte suivant.

   C. Fin de Chapitre (oScenarioRunner)
      Condition : La dernière scène du dernier acte est terminée.
      Actions :
      - Progression : Débloquer le chapitre suivant.
      - Cartes Exclusives : Parcourir les decks des bots de ce chapitre.
                            Identifier les cartes "exclusives" (non obtenables autrement).
                            Appeler unlock_card() pour ces cartes.

3. MODIFICATION DES INTERFACES (FRONTEND)

   A. Collection de Cartes (oCollectionManager / oCardCollection)
      Modification : Filtrage de l'affichage.
      Logique actuelle : Affiche toutes les cartes du jeu.
      Nouvelle logique : 
      - Parcourir toutes les cartes.
      - Si is_card_unlocked(card) == true -> Afficher normalement.
      - Sinon -> Ne pas afficher (ou afficher en grisé/cadenas selon choix futur).

   B. Menu "Contre IA" (oBotSelection / oMenu)
      Modification : Filtrage de la liste des adversaires.
      Logique actuelle : Affiche la liste statique des bots.
      Nouvelle logique :
      - Lire la liste des bots disponibles via le ProgressionManager.
      - Ne générer les boutons que pour les bots débloqués.

   C. Menu Histoire (oStoryCarousel)
      Modification : Révélation des informations.
      Logique : Utiliser les variables story_progress pour remplacer les "????" par les vrais titres et noms.

4. OUTILS D'ÉDITION (oScenarioCreatorUI)
   Ajout : Interface pour définir des récompenses manuelles.
   - Champs "Récompense Fin de Scène" (Type : Carte, Or, etc. / Valeur : ID).
   - Permet de donner une récompense spécifique sans passer par les automatismes ci-dessus.
